# P1-08TRS — Key Technical Facts

## Module Overview

- **Part number:** P1-08TRS
- **Function:** 8-point isolated relay output module

## Channel / Relay Configuration

| Specification | Details |
|---|---|
| Total output channels | 8 |
| Form A relays (SPST) | 6 |
| Form C relays (SPDT) | 2 |

## Electrical Ratings

| Parameter | Rating |
|---|---|
| Output voltage range | 6–24 VDC, 6–120 VAC |

## Status & Configuration

- The module **"does not provide any status data"**.
- The module **"does not require configuration"**.

(As a discrete output module it is controlled directly via `P1.writeDiscrete()`;
single-channel and bitmapped multi-channel writes are supported.)
