## Overview

The P1-08TD1 is a DC output module providing eight outputs that **sink** up to
1 A per point from loads powered by 3.3–24 VDC, for use with the Productivity1000
system.

- Family: Productivity1000
- Module location: any I/O position in a Productivity1000 System
- Agency approvals: UL 61010-1 and UL 61010-2-201 (File E139594, Canada & USA);
  CE (EN 61131-2 EMC, EN 61010-1, EN 61010-2-201 Safety)

## Terminal / wiring layout

- 10-position terminal block. Outputs `1`–`8`, plus a `V+` (field supply +, 12–24 VDC)
  and a `COM` terminal (the single non-isolated common / field supply return).
- Each output (open-drain MOSFET) sinks its load's return current to COM; loads are
  wired between their supply and the output pin. Schematic shows an **8 A max** fuse in
  the 12–24 V field supply and digital isolation between field and internal module logic.
- Supports single-power-source and dual-power-source wiring (per the wiring diagram).
