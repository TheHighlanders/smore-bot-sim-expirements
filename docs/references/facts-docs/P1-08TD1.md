# P1-08TD1 — Key Technical Facts

## Module Overview

The P1-08TD1 is an **8-point discrete DC output module** with a **sinking (NPN)**
output topology.

| Specification | Value |
|---|---|
| Part number | P1-08TD1 |
| Channel count | 8 |
| Output type | **Sinking (NPN)** |
| Rated output voltage | 3.3–24 VDC |

## Status & Configuration

- The module **"does not provide any status data and does not require configuration."**

(Discrete output — controlled via `P1.writeDiscrete()`; single-channel and
8-channel bitmapped writes supported.)
