# P1-08TD2 — Key Technical Facts

## Module Overview

The P1-08TD2 is an **8-point discrete DC output module** with a **sourcing (PNP)**
output topology.

| Specification | Value |
|---|---|
| Part number | P1-08TD2 |
| Channel count | 8 |
| Output type | **Sourcing (PNP)** |
| Rated output voltage | 12–24 VDC |

## Status & Configuration

- The module **"does not provide any status data"** and **"does not require configuration."**

(Discrete output — controlled via `P1.writeDiscrete()` with slot and channel
parameters; single-channel and 8-channel bitmapped writes supported.)
