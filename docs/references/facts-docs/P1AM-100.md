# P1AM-100 — Key Technical Facts

## Microcontroller & Core Specifications

| Specification | Value |
|---|---|
| Microcontroller (MCU) | **SAMD21G18** |
| Clock Speed | 48 MHz |
| Flash Memory | 256 KB |
| RAM | 32 KB |
| Storage | microSD card slot |
| RTC | 32.768 kHz crystal |

## Base Controller Communication

The P1AM-100 uses **SPI to communicate with the Base Controller** (which in turn drives the Productivity1000 I/O modules).

### SPI Pin Assignments (5 pins)

| Pin | Function |
|---|---|
| D8 | MOSI |
| D9 | CLK |
| D10 | MISO |
| A3 | CS |
| A4 | ACK |

**Critical note:** A3 and A4 cannot be used for any other device while using Productivity modules.

## Power Requirements

- **External power requirement:** a **24V** supply or a P1000 Series power supply is required to power the Base Controller and modules.
- **P1000 module power budget:** 1.25 W per slot.
- **MKR header maximum combined power:**
  - USB: 1.65 W (330 mA @ 5 V, 500 mA @ 3.3 V)
  - VIN: 3.3 W (600 mA @ 5 V, 1 A @ 3.3 V)
  - External 24V / P1000: 4.25 W (850 mA @ 5 V, 1.28 A @ 3.3 V)

## Module Capacity

- Up to **15** Productivity1000 Series I/O modules supported (requires external 24V or P1000 power supply).
