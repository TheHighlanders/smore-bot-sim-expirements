# P1-16TR — Key Technical Facts

## Module Overview

| Specification | Details |
|---|---|
| Part number | P1-16TR |
| Channel count | 16 discrete output channels |
| Output / relay type | Relay, **Form A (SPST)** |

## Electrical Ratings

| Parameter | Rating |
|---|---|
| Output voltage range | 6.25–30 VDC, 6–120 VAC |

## Status & Configuration

- Provides **no status data**.
- **Does not require configuration** — page text: "This module does not provide any status data and does not require" configuration.

(Controlled via `P1.writeDiscrete()`; supports individual channel control and
bitmapped writes affecting all 16 channels at once.)
